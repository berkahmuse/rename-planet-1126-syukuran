## The line

> Saturn is now 'The Pool Float': the only planet that would float in a bathtub, and it still shows up wearing its rings.

Saturn is the only planet less dense than water — it would genuinely float in a bathtub — and it still turns up wearing its rings, like a pool float that refuses to take off its jewellery.

## How it works

`main.ts` is a deterministic program (Node 22+): it writes the single line above to `/output/entry.txt`. No network, no randomness, no secrets.

```sh
node main.ts
cat /output/entry.txt
```
